# Gujral Hills — Public Website

This folder contains the static HTML/CSS/JS files for the public-facing
marketing website hosted on Hostinger at gujralhills.in.

## How to update
1. Edit files here locally
2. Commit and push to GitHub
3. Upload changed files to Hostinger via File Manager or FTP

## Structure (to be populated from Hostinger)
```
website/
├── index.html        ← Main landing page
├── css/
│   └── style.css
├── js/
│   └── main.js
└── images/
```

## Login button
The "Manage Project" / login button in the website should link to:
`/app/login` or the Colonizer Pro app URL.
